# Hi, I'm Anushka 👋

Founder of [Kathalyst](https://kathalyst.ai). I build AI tools that help teams understand and modernize legacy code, with a focus on COBOL and mainframe systems. Based in Mumbai. I also perform Kathak, an Indian classical dance form.

## What I work on

- **Legacy modernization.** AI-assisted code analysis, dependency mapping and documentation for COBOL systems, through Kathalyst.
- **Parsing and program analysis.** Grammars and tooling for reading legacy source, built on tree-sitter.
- **Local-first AI tools.** Software that runs on your own machine, so sensitive data stays there.
- **Systems programming.** A native macOS spreadsheet engine written in C.
